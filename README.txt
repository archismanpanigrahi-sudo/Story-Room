THE STORY ROOM — FREE WEBSITE TEMPLATE

Quickest free publishing route: GitHub Pages
1. Sign in or create a free account at https://github.com
2. Create a new public repository, for example: story-room
3. Upload index.html from this folder.
4. Open repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and / (root), then Save.
6. Wait a minute or two. GitHub will show your public website URL, which you can share on Instagram.

HOW TO ADD OR EDIT STORIES
Open index.html in a text editor. Find `const stories = [` near the bottom.
Each story has:
- title: the story title
- category: type and reading time
- excerpt: short preview shown on the homepage
- body: full story. Use \n\n between paragraphs.
Add a new object inside the array, separated from the previous one by a comma, then upload the updated index.html to GitHub.

IMPORTANT
This is a static website template. It does not have a private login or online editor; editing the source and uploading the updated file publishes changes. Do not put private or sensitive writing on a public website. Anyone with the site link can read it.
